대기 중
실시간 카메라는 HTTPS 또는 localhost에서 사용할 수 있습니다. 지원되는 브라우저에서는 Code 128을 직접 판독합니다.

판정 기준

책장의 실제 순번이 확인되지 않으면 같은 선반의 순서 오류를 확정하지 않습니다.
초록색 실선: 인식된 바코드의 실제 검출 위치 · 청록색 점선: 픽셀 경계에 기반한 책등 추정. 왼쪽 위의 작은 원은 교정된 첫 번째 꼭짓점입니다. 책등 추정은 AI 정밀 분할이 아니므로 불확실한 결과는 검토하세요.

책과 책장 등록

책장 ID와 책 제목을 입력하면 고유 식별 코드를 발급하고, 세로로 긴 Code 128 라벨 이미지를 생성합니다.

고유 ID는 책의 정체를 나타내며 기준 위치는 별도로 저장됩니다. 책을 옮겨도 라벨을 재발급할 필요가 없습니다. 기존 책을 중복 등록하지 않도록 제목을 확인하세요.
